# ITDB Abacus

A web-based educational platform designed to support children's abacus learning through interactive learning activities and games.

## Features

- **Interactive Learning Games** – Engaging activities to support children's abacus learning.
- **Admin Panel** – Administrative interface for managing platform operations.
- **Franchise Panel** – Dedicated interface for franchise-related operations.
- **PHP & MySQL Integration** – Dynamic functionality and database-driven operations.

## Technology Stack

- Core PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap (if used in the project)

## Local Setup

1. Install XAMPP.
2. Clone this repository into the `htdocs` directory.
3. Create a MySQL database named `itdbabacus`.
4. Import the database SQL file if available.
5. Configure the database connection in `administrator/includes/function.php`.
6. Start Apache and MySQL from XAMPP.
7. Open `http://localhost/itdbabacus/` in your browser.

## Security

- Do not commit database passwords or API keys.
- Do not upload private user data or database backups.
- Use appropriate database credentials for each environment.
